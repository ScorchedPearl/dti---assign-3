# DTI Assignments (Group 10)

Design Thinking assignments for the IIITA Registration Experience project (BTech V Semester).

| Folder | Stage |
| --- | --- |
| `assignment-1/` | Empathize Stage report |
| `assignment-2/` | Define Stage report and customer journey maps |
| `assignment-3/` | Ideation Stage report, mind maps and brainstorm boards |
| `source/` | Python generator and build pipeline for the Assignment 2 and 3 reports |

## Building the reports

Needs Python 3, Google Chrome and Swift (macOS).

```bash
python3 source/build.py a2 a3
```

The output is written to `source/build/`.
